# Shared frontend styles

Load these stylesheets in this order:

1. /css/layout.css
2. /css/theme.css
3. /css/components.css

## Layout

- `container`: centered content, maximum width 1180px.
- `card-grid`: one column below 768px, two from 768px,
  and three from 1200px.

## Buttons and navigation links

Use a `<button>` for an action and an `<a href="...">`
for navigation.

- `button`: navy background with white text.
- `button button--primary`: green background with navy text.
- `button button--outline`: transparent with blue text and border.

Keyboard focus styles come from theme.css.
Always provide meaningful text and a working destination or action.
